# Valorant-Slot-Machine

This is a mini project to randomise buys per agent in Valorant.
New updates have added audio to the wheel.
I have now added an Agent Randomiser alongside the wheel.

Newest Commits have added an assortment of backgrounds to choose from.
I have also made changes to the agent selection for easier usability.


All Code is created by myself, and icons produced from the Valorant Wiki Page.
Audio is taken from in games such as CS:GO, Valorant and Among Us and Edited by me.
